# PredictCNC — Frontend Single Page Application

Modern React 18 / TypeScript SPA powered by Vite and Tailwind CSS, featuring the signature Industrial Control Panel dark theme.

## Tech Stack
- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS 3.4
- **Icons**: Lucide React
- **HTTP Client**: Axios
- **Routing**: React Router v6

## Running Locally
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

## Building for Production
```bash
npm run build
```
